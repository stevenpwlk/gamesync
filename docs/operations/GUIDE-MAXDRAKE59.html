Installer GameSave Hub

Salut ! Voici comment installer GameSave Hub sur ton PC pour rejoindre notre monde The Planet Crafter.

Fais chaque étape dans l'ordre, une par une. Si à un moment l'écran ne ressemble pas à ce qui est décrit ici, arrête-toi et préviens Steven. Ce n'est pas grave, mais mieux vaut vérifier avant de continuer.

Avant de commencer, vérifie que :

✅ The Planet Crafter est déjà installé sur ton PC (Xbox Game Pass).

✅ Tu es sur ton compte Windows habituel.

✅ The Planet Crafter est complètement fermé.

✅ Tu as bien reçu le fichier GameSaveHub-pour-MaxDrake59.zip et un code d'invitation.

✅ Ton pseudo exact dans le jeu est Maxdrake59 (le "d" de "drake" en minuscule).

Étape 1 — Extraire le fichier

Trouve le fichier GameSaveHub-pour-MaxDrake59.zip que Steven t'a envoyé.

Clique dessus avec le bouton droit de la souris.

Choisis "Extraire tout..." dans le menu.

Un nouveau dossier apparaît. Ouvre-le.

Étape 2 — Installer

Dans ce dossier, trouve le fichier GameSaveHub-Setup.exe.

Clique dessus avec le bouton droit de la souris (pas le bouton gauche, pas de double-clic).

Choisis "Exécuter en tant qu'administrateur".

Windows va afficher une fenêtre bleue ou grise qui demande une autorisation. Clique sur "Oui".

Une petite fenêtre noire va s'ouvrir toute seule, puis se refermer toute seule après quelques secondes. C'est normal, ne touche à rien.

Rien d'autre ne s'ouvre après ça. Il faut lancer l'application toi-même :

Clique sur le bouton Démarrer de Windows, tape GameSave Hub, puis clique dessus pour l'ouvrir.

Étape 3 — Remplir le formulaire

Une fenêtre s'ouvre et te demande trois informations.

Nom de ce PC : ne change rien, c'est déjà rempli.

Ton pseudo Planet Crafter : écris Maxdrake59 exactement comme ça.

Code d'invitation : recopie le code que Steven t'a envoyé.

Clique sur "Continuer".

Étape 4 — Configurer ton monde (une seule fois)

Après l'étape 3, l'écran d'accueil va afficher l'une des deux phrases suivantes. Regarde bien laquelle, et suis seulement les instructions qui correspondent.

🅰️ Si l'écran affiche : "Un monde partagé existant a été trouvé"

Clique simplement sur "Rattacher ce monde". C'est tout, tu n'as rien d'autre à faire dans le jeu.

🅱️ Si l'écran affiche : "Configurons ce PC"

C'est la configuration normale la première fois. Il faut lancer le jeu deux fois de suite. Suis ces étapes dans l'ordre :

1. Clique sur "Configurer ce PC".

2. L'écran affiche un nom avec un bouton "Copier le nom". Clique sur ce bouton.

3. Clique sur "Lancer The Planet Crafter".

4. Dans le jeu, crée une nouvelle partie. Pour son nom, colle ce que tu as copié (touches Ctrl + V en même temps). Le nom doit être exactement GSH-MONDE-PARTAGE, sans rien changer.

5. Entre une fois dans cette nouvelle partie, puis sauvegarde et ferme complètement le jeu (pas juste réduire la fenêtre : il ne doit plus du tout tourner).

6. Reviens sur GameSave Hub. Il va afficher "Installation du monde partagé…" puis "Configuration unique — étape 2 sur 2".

7. Clique de nouveau sur "Lancer The Planet Crafter". Cette fois, le jeu qui s'ouvre contient déjà notre vraie sauvegarde commune — c'est normal, c'est fait exprès.

Si l'écran affiche autre chose que ces deux phrases, ne clique sur rien. Fais une photo de l'écran et envoie-la à Steven.
Étape 5 — Jouer, maintenant et plus tard

Pour jouer et sauvegarder : ouvre GameSave Hub, clique sur "Prendre la main", attends que ça affiche "Tout est prêt pour jouer", puis clique sur "Lancer The Planet Crafter". Joue, sauvegarde, puis ferme complètement le jeu. Le reste se fait tout seul.

Pour rejoindre quelqu'un qui joue déjà : GameSave Hub te le dira à l'écran d'accueil. Rejoins depuis le menu multijoueur du jeu, comme d'habitude.

En cas de doute à n'importe quel moment : arrête-toi, fais une photo de l'écran, et envoie-la à Steven avant de continuer. Rien de tout ça n'abîme ta sauvegarde tant que tu n'as pas cliqué sur un bouton.
